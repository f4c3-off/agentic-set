# 🗄️ Outdated Frameworks & Tools

Questo file funge da archivio storico per tutti quei framework, orchestrazioni e strumenti agentici che non sono più aggiornati o il cui repository risulta abbandonato. Vengono spostati qui per mantenere pulita la knowledge base principale con le sole tecnologie attuali.

## Orchestrazione e Framework

- [Bytechef](https://github.com/bytechefhq/bytechef) - Piattaforma open source che unificava orchestrazione di agenti AI e workflow automation. (Repository rimosso o inattivo).
- [Paperclip](https://github.com/paperclipai/paperclip) - L'applicazione open-source per la gestione degli agenti nell'ambiente di lavoro. (Superato da nuove soluzioni come Orkestr e Agent Swarm, repository non aggiornato).
