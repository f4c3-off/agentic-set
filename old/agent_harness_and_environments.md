# ⚙️ Agent Harness & Environments

This file contains tools requiring system modifications, environment setup, or used to improve the harness itself.
These are not meant for the agent to "use" during a task, but for the human to set up the agent environment.

- [Loop Engineer Template](https://github.com/AI-Builder-Club/loop-engineer-template) - Template per l'ingegneria dei loop agentici
- [Free Claude Code](https://github.com/Alishahryar1/free-claude-code) - Strumento di supporto per utilizzare Claude Code
- [Stirrup](https://github.com/ArtificialAnalysis/Stirrup) - Harness e ambiente di esecuzione per testare agenti
- [Loop Engineering](https://github.com/cobusgreyling/loop-engineering) - Strumenti per l'ingegneria dei cicli di feedback
- [Paperclip Companies](https://github.com/paperclipai/companies) - Progetto di supporto e configurazione per Paperclip
- [Compose for Agents](https://github.com/docker/compose-for-agents) - Strumento Docker per orchestrazione di ambienti agentici
- [FreeDomain](https://github.com/DigitalPlatDev/FreeDomain) - Servizi web di supporto
- [Gemini Web2API](https://github.com/Sophomoresty/gemini-web2api) - Adattatore API per Gemini
- [ECC](https://github.com/affaan-m/ECC) - Strumento e libreria di supporto
- [Boxlite AI](https://github.com/boxlite-ai) - Piattaforma di supporto AI
- [Claude Memory Compiler](https://github.com/coleam00/claude-memory-compiler) - Tool di gestione memoria estesa per Claude
- [WindsurfAPI](https://github.com/dwgx/WindsurfAPI/blob/master/README.en.md) - Wrapper API non ufficiale per l'editor Windsurf
- [Fabro](https://github.com/fabro-sh/fabro) - Tool di supporto alla programmazione AI
